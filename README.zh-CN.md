# LaTeX 公式编号

这是一个思源笔记插件，用于自动为当前文档中的块级公式添加和修正
LaTeX `\tag{x}` 编号。

## 功能

- 仅扫描块级公式，不处理行级公式。
- 自动添加缺失的 `\tag{x}`。
- 按当前文档顺序修正错误编号、重复编号和跳号。
- 监听公式新增、删除、编辑和文档切换后自动重新编号。
- 在顶部工具栏提供开启/关闭按钮。
- 关闭插件功能时自动清除当前文档中的编号。

## 开发

```bash
pnpm i
pnpm run dev
```

建议将项目目录放在：

```text
{思源工作空间}/data/plugins/LatexTag
```

## 打包

```bash
pnpm run package
```

打包后会生成用于发布的 `package.zip`。
